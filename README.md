# মাছরাঙা পোর্টাল (hermes-portal)

মাছরাঙা (Hermes) বটের ওয়েব পোর্টাল: ড্যাশবোর্ড, কাজের লিস্ট, রুটিন, স্বাস্থ্যের চার্ট, পড়াশোনার হিসাব আর সেটিংস — সব এক জায়গায়।

## কীভাবে কাজ করে

- **একই ডাটাবেস:** বটের Turso DB-ই সরাসরি পড়ে-লেখে (`lib/db.ts`), কোনো আলাদা API নেই। পোর্টালে টিক দিলে বটও সেটা জানে, বটে কিছু বললে পোর্টালেও দেখা যায়।
- **পাসওয়ার্ড নেই:** ইউজার বটকে `portal` লেখে → বট ১৫ মিনিটের এক-বারের লিংক দেয় (`hermes_portal_codes` টেবিল) → ক্লিক করলেই ৩০ দিনের সেশন কুকি (`lib/session.ts`, JWT)। যে বট চালায় শুধু সে-ই ঢুকতে পারে।
- প্রতিটা কোয়েরি শুধু নিজের `master_id` এর ডাটা ছোঁয় (`lib/data.ts`)।

## পেজ

| পথ | কী আছে |
|---|---|
| `/` | ড্যাশবোর্ড: আজকের কাজ, রুটিন, পরের রিমাইন্ডার, শেষ স্বাস্থ্যের মাপ, প্ল্যানের মেয়াদ |
| `/todo` | কাজ যোগ/টিক/বাদ (বটের সাথে sync) |
| `/routine` | সাপ্তাহিক রুটিন, দিন ধরে |
| `/health` | প্রেশার-সুগার-ওজন-ঘুম-মনের SVG চার্ট, ওষুধ, উপসর্গ |
| `/study` | MCQ-র হিসাব: মোট, সঠিকের হার, দিন ধরে বার চার্ট |
| `/settings` | সকালের to-do, খবরের সময়/বিষয়, মন চেক-ইন, রিপোর্ট, টাকার হিসাব |

## চালানো

```bash
cp .env.example .env    # মান বসাও (নিচে দেখো)
npm install
npm run dev             # http://localhost:3100
```

`.env`:
- `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN` — **বটের (Hermes2) .env এর ঠিক একই মান**
- `SESSION_SECRET` — লম্বা এলোমেলো স্ট্রিং: `openssl rand -hex 32`

লোকালে লগইন টেস্ট: বটের `.env` এ `PORTAL_URL=http://localhost:3100` দিয়ে ডিপ্লয়/চালাও, তারপর বটে `portal` লেখো — যে লিংক আসবে সেটাই।

## ডিপ্লয়

অন্য অ্যাপগুলোর মতোই (Firebase App Hosting / Vercel — Next.js যেখানে চলে)। ডিপ্লয়ের পর:

1. হোস্টিংয়ে env ৩টা বসাও
2. **বটের** `.env` এ `PORTAL_URL=https://<পোর্টালের ডোমেইন>` দিয়ে বট আবার ডিপ্লয় করো (`python -m modal deploy modal_app.py`)
3. বটে `portal` লিখে দেখো লিংক আসে আর ঢোকা যায় কিনা
